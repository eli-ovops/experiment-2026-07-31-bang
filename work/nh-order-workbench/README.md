# NH 订单整理工作台

一个完全在浏览器本地运行的静态工具，用于把 Five Star Furniture PDF 订单整理成 Excel。

## Windows 日常使用

1. 双击 `NH订单整理工作台_Windows.html`，使用 Chrome 或 Edge 打开。
2. 浏览器打开后，把当天的一个或多个 PDF 拖入页面。
3. 检查浅黄色的待确认行；需要时直接修改单元格。
4. 点击“导出 Excel”。

Windows HTML 是单文件版本，不需要安装、不需要 Python，也不依赖旁边的其他程序文件。

## macOS 日常使用

macOS 也可以直接双击 HTML；原来的 `启动工作台.command` 仅供旧版多文件交付使用，Windows 无法运行该脚本。

## 当前规则

- 排除 CUBA 系列。
- 餐桌、边几和其他非椅子产品不进入主表。
- 每个符合条件的椅子产品独立一行。
- `CHANGE` 中数量大于 0 的椅子进入主表，类型保留为 `CHANGE`。
- `CHANGE` 中数量为 0 的椅子作为完整 PDF 页面进入 `取消订单` 工作表。
- 订单备注优先于产品描述；备注里的 Leather、Stain、FAB 会覆盖描述值。
- 产品名和材料值按字段标签、结构及上下文提取，不依赖附件中的固定值名单。
- 自动识别不确定的字段会标黄，保留人工复核。

## 隐私与限制

- PDF 和生成过程不会上传到服务器。
- 工具不保存订单；刷新或关闭页面后，页面中的临时结果会消失。
- 当前只支持与样例版式一致的文本型 PDF，不支持扫描图片型 PDF。
- 已使用 Chrome 完成样例验收；建议日常也使用 Chrome。

## 已验证样例

对 `Jul03,26(1).pdf` 与 `Jul04,26.pdf` 的联合测试结果：

- 21 个 PDF 页面
- 14 条主表记录
- 1 个取消订单页面
- 2 个 Excel 工作表
- CUBA、餐桌和边几均未进入主表
