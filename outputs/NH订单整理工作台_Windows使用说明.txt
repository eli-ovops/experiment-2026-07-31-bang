NH 订单整理工作台 - Windows 使用说明

1. 将“NH订单整理工作台_Windows.html”保存到电脑。
2. 双击 HTML 文件，建议选择 Microsoft Edge 或 Google Chrome 打开。
3. 把当天收到的一个或多个 PDF 拖入页面。
4. 检查浅黄色的待确认行；如有需要，直接修改表格。
   明细表可在窗口内上下滚动，并可用“向左 / 向右”按钮查看全部字段。
5. 点击“导出 Excel”。

识别规则：
- 以订单备注为准；备注中的 Leather、Stain、FAB 会覆盖产品描述。
- 不使用固定产品名、皮色、木色或布色名单；同版式的新值会按字段标签和上下文提取。
- CUBA 排除；每个椅子产品一行。
- CHANGE 只有数量为 0 才进入“取消订单”；数量大于 0 仍进入明细表。

说明：
- 这是单文件离线工具，不需要安装软件，也不需要 Python。
- PDF 内容不会上传到服务器。
- 请勿用 Word、记事本或微信内置预览器打开 HTML。
- 如果 Windows 询问打开方式，请选择 Edge 或 Chrome，并可勾选“始终使用”。
- 当前支持与样例版式一致的文本型 PDF，不支持扫描图片型 PDF。
- “待确认行”按有问题的产品行计数，下方会另行显示待确认字段总数。
- 源 PDF 确实没有客户名或 Stain 时会保留为空并标为待确认，不会猜测。
- 客户收到后，只需要 HTML 文件即可使用。
